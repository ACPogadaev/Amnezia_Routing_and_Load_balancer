# Открытые списки IPv4/CIDR

Снимки предоставленных списков от **3 ноября 2026 года**, нормализованные тем же
загрузчиком, который используется при установке. Они содержат только IPv4/CIDR:
комментарии удалены, дубликаты и вложенные сети объединены, служебные диапазоны
отфильтрованы по вложенному реестру IANA.

| Файл | Сетей | Назначение |
|---|---:|---|
| [balanced-ipv4-2026-11-03.cidr.txt](balanced-ipv4-2026-11-03.cidr.txt) | 6202 | Первый список: распределение между доступными выходами |
| [ai-pinned-ipv4-2026-11-03.cidr.txt](ai-pinned-ipv4-2026-11-03.cidr.txt) | 624 | Второй список: только выбранный выход |

Из корня Git-репозитория после подготовки собственных AWG-профилей:

```bash
sudo bash install.sh --egress /root/exit1.conf --egress /root/exit2.conf --egress /root/exit3.conf --balanced-routes routes/balanced-ipv4-2026-11-03.cidr.txt --pinned-routes routes/ai-pinned-ipv4-2026-11-03.cidr.txt --pin-egress 1 --check-only
```

Для установки уберите `--check-only`. Номер `--pin-egress` соответствует порядку
переданных `--egress`, поэтому выбирайте его для своих серверов.

При пересечении списков приоритет имеет второй. Названия файлов описывают цель
политики, а классификация выполняется по IP: общие адреса и широкие сети могут
захватывать другие сервисы. Файлы, скачиваемые AI-агентом с внешнего сайта,
маршрутизируются по адресу этого сайта. Снимки не обновляются автоматически и
не гарантируют полноту адресов всех AI-сервисов.

Списки не содержат профилей VPN, паролей, ключей или данных для SSH-подключения.
